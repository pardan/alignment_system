Radio & alignment configuration

Radio address, SNMP access, and sweep candidate frequencies.

Required for every SNMP set operation.

Separate integer values with commas, spaces, or new lines. Example: 10507500.

Alignment behaviour

Movement timing and retry limits for the automatic alignment cycle.

Stops horizontal sweep when the configured target is reached.

Used in both stopping modes.

After target is reached, example: best -90 with 3 dB tolerance permits -91 to -93; -94 returns to the best sweep position.

Allowed range: 1–3.

Decimals are supported, for example 0.5.

Automatic recovery

Controls when signal loss may start a recovery scan. A loss is RSSI -1 or below the configured threshold; Manual Start always bypasses cooldown.

Consecutive valid loss readings required before the first boot scan.

Default: -90. A reading strictly below this value triggers signal-loss handling.

Continuous loss duration after signal was previously normal.

Leave empty for Unlimited automatic attempts.

Controller coordination

Multi mode pairs exactly two configured Raspberry Pis. The lower numeric IP becomes master; other network devices are ignored.

Enter only the paired Raspberry Pi, not a network range.

Generate once, then copy the same token to the paired Raspberry Pi. At least 16 characters.

How often the master compares both RSSI values and switches the active controller.

Keep the active controller until the other controller is stronger by at least this many dB. Set 0 to switch for any improvement.

Consecutive paired-controller check failures before standalone failover enables local recovery.
